Ростовская эмаль

Дипломная работа

Интернет-магазин ростовской финифти

Сайт мастерской ростовской финифти: каталог украшений, икон и сувениров с ручной росписью по эмали, поиск, корзина, избранное и оформление заказа.

Выпускная квалификационная работа, которую я продолжаю поддерживать.

Стек: HTML, CSS, JavaScript без фреймворков, PHP для форм, свой генератор статических страниц на PowerShell.

Галерея проекта

Описание проекта

  • Каталог из 26 изделий с фильтрами по категории, материалу, коллекции и цене, сортировкой и счётчиками.
  • Поиск с подсказками и отдельной страницей результатов.
  • Корзина и избранное в localStorage: синхронизируются между вкладками, цены всегда берутся из каталога.
  • Оформление заказа с проверкой полей. Сервер сам берёт цены из каталога и присваивает номер заказа.
  • Адаптивная вёрстка, доступность, разметка schema.org, sitemap.xml и тесты обработчика форм.

Опубликована демо-версия: магазин не настоящий, контакты условные, заказы никуда не отправляются.
