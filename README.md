# Портфолио Вячеслава Шапрана

Сайт-портфолио Python-разработчика: проекты, навыки и контакты.

**Сайт:** https://123-liard-eight-26.vercel.app

## Стек

Статический сайт на HTML и CSS, без фреймворков и сборки. На главной есть небольшой скрипт на чистом JavaScript для параллакса. Публикуется на Vercel из ветки `main`.

## Как запустить

```bash
npx http-server -p 8080
```
